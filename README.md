# VoxelCraft — воксельная песочница для Яндекс Игр

Оригинальная воксельная игра в жанре «песочница с блоками» (как Minecraft): процедурный
мир, разрушение и установка блоков, режим полёта, смена дня и ночи, сохранение прогресса.
Все текстуры и звуки генерируются процедурно — никаких сторонних ассетов.

Игра полностью готова к публикации на **Яндекс Играх**: работает на ПК и телефонах,
интегрирована с SDK (сохранения в облаке, реклама с вознаграждением, межстраничная реклама,
GameplayAPI/LoadingAPI, локализация ru/en).

## Возможности

- 🌍 Процедурный бесконечный мир: холмы, горы, пляжи, вода, деревья, снежные вершины
- 🐇 Мирные мобы: зайчики, барашки, слизни и птицы; ночью появляются уменьшенная **Хмарь** со страшным лицом и чёрные пауки
- 🧱 27 видов блоков, в том числе деревянные и каменные полублоки (верх/низ), факелы с локальным светом, печка и две руды
- 🌿 Декоративная трава, папоротник, клевер и цветы; трава иногда даёт пшеницу
- 🏹 Детализированный лук с настоящими стрелами; из убитых монстров выпадает подбираемый опыт
- 🔥 Руда и уголь выпадают предметами, которые можно поднять; из руды в печке получается слиток, из пшеницы — хлеб
- 🎒 Креатив (всё бесконечно, полёт, неуязвимость) и выживание (запасы, крафт, еда); переключение в главном меню и на паузе
- 🌦 Погода: дождь и снегопад со звуками, гроза со вспышками молний; ночью поют сверчки
- ⛏ Разрушение с анимацией трещин (5 стадий) и пылью, частицы, процедурные звуки
- 🕊 Полёт в креативе (G / двойной пробел / кнопка), мягкая тряска камеры при беге
- 🌅 Полный цикл дня и ночи со звёздами, солнцем и луной
- 💾 Автосохранение мира, режима, инвентаря, опыта и построек (облако Яндекса или localStorage), лидерборд «Построено блоков»
- 📱 Сенсорное управление: джойстик, обзор свайпом, кнопки действий
- 🎁 Реклама за вознаграждение — «Набор строителя» с декоративными блоками
- 🌐 Локализация русский/английский

## Запуск и сборка

```bash
npm install        # зависимости (three, esbuild)
npm run build      # собрать game.js
npm run serve      # локальный сервер на http://localhost:8080
npm run zip        # собрать game.js + voxelcraft-yandex.zip для загрузки в консоль
npm test           # тесты мира, полублоков, крафта, мобов и подбираемых предметов
```

Для разработки: `npm run dev` (без минификации, с sourcemap).

## Публикация на Яндекс Играх

1. Выполните `npm run zip` — получится `voxelcraft-yandex.zip`.
2. Откройте [Консоль разработчика Яндекс Игр](https://games.yandex.ru/console) → «Создать игру».
3. Загрузите архив (`index.html`, `styles.css`, `game.js` в корне — уже включены).
4. Заполните карточку игры (название, описание, категория «Песочницы»/«Аркады»,
   ориентация — **альбомная**, устройства — телефон + компьютер).
5. Проверьте игру в черновике (песочница консоли), затем отправьте на модерацию.

Что уже сделано под требования платформы:

- вызовы `LoadingAPI.ready()` и `GameplayAPI.start()/stop()` (старт/остановка геймплея);
- `showFullscreenAdv` при выходе в меню после игры и `showRewardedVideo` для бонуса;
- пауза и приглушение звука при сворачивании вкладки/экрана и на время рекламы;
- игра не падает без интернета к SDK (локальный фолбэк на localStorage);
- альбомная ориентация с подсказкой поворота экрана на телефоне;
- весь код и ассеты внутри архива, внешних загрузок (шрифты/картинки) нет.

## Управление

| ПК | Телефон |
|----|---------|
| WASD — движение | Джойстик слева |
| Мышь — обзор | Свайп справа — обзор |
| ЛКМ — копать, ударить моба или стрелять из лука | Тап / кнопка «КОП» — копать или стрелять |
| ПКМ — поставить или открыть печку | Кнопка «СТАВ» — поставить или открыть печку |
| 1–9 / колесо — выбор предмета | Тап по слоту хотбара (панель прокручивается) |
| E — рюкзак и крафт | Кнопка «ИНВ» |
| F — съесть хлеб (если выбран) или яблоко | Кнопка «ЕСТЬ» |
| Прыжок — пробел | Кнопка «▲» |
| Бег — Ctrl | Джойстик до упора |
| Полёт в креативе — G / двойной пробел | Кнопка «ЛЕТ», «▼»/«▲» в полёте |
| Пауза — Esc | Кнопка «II» |

## Юридическое

VoxelCraft — самостоятельная игра. Механики жанра (блоки, строительство) не защищены
авторским правом, но код, текстуры, звуки, название и тексты здесь оригинальные и не
используют материалы Mojang/Microsoft. Не называйте игру «Minecraft» и не копируйте
ассеты оригинала.

## Выживание и крафт

- ❤️ Здоровье (10 сердец), урон от падений и медленная регенерация. Хлеб лечит 3 сердца, яблоко — 2.
- 🌑 Хмарь и пауки появляются ночью за пределами поля зрения с интервалом 20–35 секунд и ограничением на число монстров. Рассвет уничтожает Хмарь, но не даёт за это опыта.
- ⛏ Камень даёт булыжник, железная/угольная руда — подбираемые предметы. Убитые монстры оставляют сферы опыта (уровень сохраняется).
- 🌾 Из травы выпадает пшеница; на листве иногда находятся яблоки.
- 🧰 Нажмите **E** (или «ИНВ») для крафта: бревно → доски; доски/булыжник → полублоки; уголь + доски → факелы; булыжник → печка; слиток + доски → стрелы.
- 🔥 Поставьте печку и нажмите на неё ПКМ/«СТАВ»: руда + топливо → слиток; 3 пшеницы + топливо → хлеб. Топливо — один уголь **или** одна доска.
- 🧱 Верхний полублок ставится на нижнюю грань/верхнюю половину боковой грани. Два одинаковых полублока в одной ячейке превращаются в целый блок.
- ♾ В креативе блоки и стрелы бесконечны, урон не наносится и доступен полёт. Сменить режим можно в главном меню или на паузе; выбор сохраняется.
