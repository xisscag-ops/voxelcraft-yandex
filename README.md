# VoxelCraft — воксельная песочница для Яндекс Игр

Оригинальная воксельная игра в жанре «песочница с блоками» (как Minecraft): процедурный
мир, разрушение и установка блоков, режим полёта, смена дня и ночи, сохранение прогресса.
Все текстуры и звуки генерируются процедурно — никаких сторонних ассетов.

Игра полностью готова к публикации на **Яндекс Играх**: работает на ПК и телефонах,
интегрирована с SDK (сохранения в облаке, реклама с вознаграждением, межстраничная реклама,
GameplayAPI/LoadingAPI, локализация ru/en).

## Возможности

- 🌍 Процедурный бесконечный мир: холмы, горы, пляжи, вода, деревья, снежные вершины
- ⚔️ Режимы **«Выживание»** и **«Креатив»** (выбор при новом мире, хранится в сейве; старые сохранения открываются в креативе)
- 🎒 Инвентарь на 36 ячеек (E / кнопка 🎒): стопки до 64, ЛКМ/ПКМ-управление стопками, предмет следует за курсором
- 🔨 Крафт (выживание): доски, палки, кирки, топор, мечи, стекло, кирпич, светокамень, снег и другое
- 🛠 Инструменты ускоряют ломание (кирка ×0.85/×0.55, топор ×0.5) и наносят урон (меч 2/3, рукой 1)
- 🐇 Мобы: зайчики и овцы (2–3 HP, убегают после удара), барашки, слизни, птицы (не бьются), ночная Хмарь — с красной вспышкой урона, отбросом и писком
- ❤️ Здоровье: красная вспышка, встряска камеры и интерфейса, мигание сердечек; в креативе игрок бессмертен
- 🧱 19 видов блоков, хотбар (первые 9 ячеек инвентаря) с выбором колесом/цифрами/тапом
- 🌿 Декоративная трава, папоротник, клевер и цветы
- 🌦 Погода: дождь и снегопад со звуками, гроза со вспышками молний; ночью поют сверчки
- ⛏ Разрушение с анимацией трещин (5 стадий) и пылью, частицы, процедурные звуки
- 🕊 Полёт в креативе (двойной пробел / кнопка); F — съесть яблоко
- 🌅 Полный цикл дня и ночи со звёздами, солнцем и луной
- 💾 Автосохранение мира, построек, инвентаря и режима (облако Яндекса или localStorage), лидерборд «Построено блоков»
- 📱 Сенсорное управление: джойстик, обзор свайпом, кнопки действий, инвентарь 🎒
- 🎁 Реклама за вознаграждение — «Набор строителя» с декоративными блоками (в каталоге креатива)
- 🌐 Локализация русский/английский

## Как запустить

### Локально

```bash
npm install        # зависимости (three, esbuild)
npm run build      # собрать game.js
npm run serve      # локальный сервер на http://localhost:8080
npm test           # смоук-тесты (мир, мешер, рейкаст, инвентарь, крафт)
npm run zip        # собрать game.js + voxelcraft-yandex.zip для загрузки в консоль
```

Для разработки: `npm run dev` (без минификации, с sourcemap).

### Через GitHub Pages

Игра — статичный сайт (`index.html` + `styles.css` + собранный `game.js` в корне
репозитория), поэтому GitHub Pages работает без дополнительного деплоя:

1. Выполните `npm run build` и закоммитьте обновлённый `game.js` в `main` (push).
2. В репозитории на GitHub откройте **Settings → Pages → Build and deployment → Source:
   «Deploy from a branch» → Branch: `main`, Folder: `/ (root)` → Save**.
3. Через пару минут игра будет доступна по адресу
   `https://<ваш-логин>.github.io/voxelcraft-yandex/`.

Сохранения при этом хранятся в localStorage браузера (облако Яндекса включается
только внутри платформы Яндекс Игр).

## Публикация на Яндекс Играх

1. Выполните `npm run zip` — получится `voxelcraft-yandex.zip`.
2. Откройте [Консоль разработчика Яндекс Игр](https://games.yandex.ru/console) → «Создать игру».
3. Загрузите архив (`index.html`, `styles.css`, `game.js` в корне — уже включены).
4. Заполните карточку игры (название, описание, категория «Песочницы»/«Аркады»,
   ориентация — **альбомная**, устройства — телефон + компьютер).
5. Проверьте игру в черновике (песочница консоли), затем отправьте на модерацию.

Что уже сделано под требования платформы:

- вызовы `LoadingAPI.ready()` и `GameplayAPI.start()/stop()` (старт/остановка геймплея);
- `showFullscreenAdv` при выходе в меню после игры и `showRewardedVideo` для бонуса;
- пауза и приглушение звука при сворачивании вкладки/экрана и на время рекламы;
- игра не падает без интернета к SDK (локальный фолбэк на localStorage);
- альбомная ориентация с подсказкой поворота экрана на телефоне;
- весь код и ассеты внутри архива, внешних загрузок (шрифты/картинки) нет.

## Управление

| ПК | Телефон |
|----|---------|
| WASD — движение | Джойстик слева |
| Мышь — обзор | Свайп справа — обзор |
| ЛКМ (удерживать) — сломать / ударить моба | Тап по экрану — сломать / ударить |
| ПКМ — поставить | Кнопка «🧱» — поставить |
| 1–9 / колесо — выбор слота | Тап по слоту хотбара |
| E — инвентарь и крафт | Кнопка «🎒» (тап — взять, долгое нажатие — по одному) |
| F — съесть яблоко | — |
| Прыжок — пробел | Кнопка «▲» |
| Бег — Ctrl | Джойстик до упора |
| Полёт — двойной пробел (только креатив) | Кнопка «🕊», «▼»/«▲» в полёте |
| Пауза — Esc | Кнопка «⏸» |

## Юридическое

VoxelCraft — самостоятельная игра. Механики жанра (блоки, строительство) не защищены
авторским правом, но код, текстуры, звуки, название и тексты здесь оригинальные и не
используют материалы Mojang/Microsoft. Не называйте игру «Minecraft» и не копируйте
ассеты оригинала.

## Режимы и выживание
- ⚔️ **Выживание:** сломанные блоки падают в инвентарь (трава → земля, камень → булыжник,
  стекло ничего не даёт, листва иногда даёт листву), поставленные блоки расходуются,
  полёта нет, мобы наносят урон.
- ✨ **Креатив:** все блоки бесконечны, ломаются за ~0.12 с, полёт двойным пробелом,
  игрок бессмертен, сердечки скрыты.
- 🎒 **Инвентарь (E / 🎒):** 36 ячеек, хотбар — первые 9; ЛКМ — взять/положить/поменять
  стопку, ПКМ — по одному / взять половину. В креативе слева — каталог всех блоков и
  предметов, в выживании — список рецептов (доступные подсвечены зелёным).
- 🛠 **Инструменты:** без кирки камень ломается в 2.6 раза дольше, деревянная кирка ×0.85,
  каменная ×0.55; топор ускоряет дерево ×0.5 (без него ×1.6); меч: урон 2 (дерево) /
  3 (камень), рукой 1.
- ❤️ Здоровье (10 сердец) и урон от падений; медленная регенерация
- 🌑 Ночной охотник **Хмарь**: подкрадывается к игроку и бьёт; ЛКМ — удар (3 удара), рассвет сжигает
- 🍎 Яблоки иногда падают с листвы: **F** — съесть (+2 сердца)
